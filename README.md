# aiohttp_ads

Простое REST API для управления объявлениями, построенное с использованием aiohttp и SQLAlchemy.

## Описание

Проект предоставляет API для создания, чтения, обновления и удаления объявлений (CRUD). Каждое объявление имеет заголовок, описание, дату создания и владельца.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL репозитория>
   cd aiohttp_ads
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   venv\Scripts\activate     # Для Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настройте переменные окружения:
   Скопируйте файл `.env_example` в `.env` и заполните необходимые значения:
   ```bash
   cp .env_example .env
   ```
   Затем отредактируйте `.env`, указав свои значения для подключения к базе данных PostgreSQL.

   Переменные окружения:
   - `POSTGRES_USER`: пользователь PostgreSQL (по умолчанию: postgres)
   - `POSTGRES_PASSWORD`: пароль PostgreSQL (по умолчанию: postgres)
   - `POSTGRES_HOST`: хост базы данных (по умолчанию: localhost)
   - `POSTGRES_PORT`: порт базы данных (по умолчанию: 5432)
   - `POSTGRES_DB`: имя базы данных (по умолчанию: ads_db)
   - Либо укажите полную строку подключения в `DATABASE_URL` (например, `postgresql+asyncpg://user:password@host:port/db`)

## Использование

1. Инициализируйте базу данных (создайте таблицы):
   ```bash
   python init_db.py
   ```

2. Запустите приложение:
   ```bash
   python app.py
   ```
   Сервер будет доступен по адресу http://0.0.0.0:8080

3. Проверьте работоспособность сервера:
   ```bash
   curl http://localhost:8080/health
   ```
   Ожидаемый ответ: `{"status": "ok"}`

## API endpoints

- `GET /health` — проверка работоспособности сервера.
- `GET /ads` — получить список всех объявлений.
- `POST /ads` — создать новое объявление.
  Тело запроса (JSON):
  ```json
  {
    "title": "Заголовок объявления",
    "description": "Описание объявления",
    "owner": "Владелец"
  }
  ```
- `GET /ads/{ad_id}` — получить объявление по ID.
- `PATCH /ads/{ad_id}` — обновить объявление по ID (частичное обновление).
  Тело запроса (JSON) с полями, которые нужно обновить (title, description, owner).
- `DELETE /ads/{ad_id}` — удалить объявление по ID.

## Переменные окружения

Приложение использует следующие переменные окружения (можно задать в файле `.env`):

| Переменная           | Описание                                 | Значение по умолчанию |
|----------------------|------------------------------------------|-----------------------|
| POSTGRES_USER        | Пользователь PostgreSQL                  | postgres              |
| POSTGRES_PASSWORD    | Пароль PostgreSQL                        | postgres              |
| POSTGRES_HOST        | Хост базы данных                         | localhost             |
| POSTGRES_PORT        | Порт базы данных                         | 5432                  |
| POSTGRES_DB          | Имя базы данных                          | ads_db                |
| DATABASE_URL         | Полная строка подключения к БД (asyncpg) | Если задана, переопределяет отдельные переменные |

## Структура проекта

- `app.py` — основной файл приложения с настройкой aiohttp, маршрутами и обработчиками.
- `init_db.py` — скрипт для инициализации базы данных (создание таблиц).
- `requirements.txt` — список зависимостей Python.
- `.env_example` — пример файла переменных окружения.
- `http_test_api.http` — файл с примерами запросов для тестирования API (можно использовать в VS Code или с помощью инструментов вроде httpie).
- `1.py` — пример скрипта (возможно, для тестирования).

## Тестирование

Вы можете использовать файл `http_test_api.http` для отправки тестовых запросов напрямую из VS Code (если установлено расширение REST Client) или скопировать запросы в ваш HTTP-клиент.

Запуск всех запросов из файла `http_test_api.http` с помощью расширения REST Client позволяет автоматически проверить работу всех эндпоинтов API.
