# aiohttp_ads

Проект на основе aiohttp для управления объявлениями (ads). Включает REST API, работу с базой данных PostgreSQL, Docker-контейнеризацию и примеры запросов.

## Структура проекта

- `app.py` — основное приложение aiohttp с маршрутами и обработчиками.
- `init_db.py` — скрипт для инициализации базы данных (создание таблиц и начальных данных).
- `requirements.txt` — зависимости Python.
- `Dockerfile` — образ для запуска приложения.
- `docker-compose.yml` — определение сервисов (app, db) для docker-compose.
- `http_test_api.http` — файл с примерами HTTP-запросов для тестирования API (поддерживается в VS Code и IDEA).
- `.env_example` — пример файла переменных окружения.
- `.gitignore` — стандартные исключения для git.
- `.dockerignore` — исключения для Docker.

## Установка и запуск

### Локальный запуск (без Docker)

1. Склонируйте репозиторий и перейдите в директорию проекта.
2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   source venv/bin/activate   # на Windows: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Скопируйте `.env_example` в `.env` и заполните необходимые переменные (например, подключение к БД).
5. Инициализируйте базу данных:
   ```bash
   python init_db.py
   ```
6. Запустите приложение:
   ```bash
   python app.py
   ```
   Приложение будет доступно по адресу `http://localhost:8080`.

### Запуск с Docker

1. Убедитесь, что установлены [Docker](https://www.docker.com/get-started) и [docker-compose](https://docs.docker.com/compose/install/).
2. Скопируйте `.env_example` в `.env` и настройте переменные окружения (включая параметры для PostgreSQL).
3. Запустите сборку и контейнеры:
   ```bash
   docker-compose up --build
   ```
   Приложение будет доступно по `http://localhost:8080`, а база данных PostgreSQL — на стандартном порту 5432 (или как указано в `.env`).

4. Для остановки и удаления контейнеров:
   ```bash
   docker-compose down
   ```

## API endpoints

Основные эндпоинты (примеры, см. `app.py` для полного списка):

- `GET /ads` — получить список объявлений.
- `POST /ads` — создать новое объявление.
- `GET /ads/{id}` — получить объявление по ID.
- `PUT /ads/{id}` — обновить объявление.
- `DELETE /ads/{id}` — удалить объявление.

Примеры запросов см. в файле `http_test_api.http`.

## Тестирование

Вы можете использовать файл `http_test_api.http` в VS Code (с расширением REST Client) или в JetBrains IDEA для отправки тестовых запросов к запущенному API.

## Переменные окружения

См. `.env_example` для списка переменных, которые можно настроить:

- `DB_HOST` — хост базы данных.
- `DB_PORT` — порт базы данных.
- `DB_NAME` — имя базы данных.
- `DB_USER` — пользователь БД.
- `DB_PASS` — пароль БД.
- `APP_HOST` — хост для приложения (по умолчанию `0.0.0.0`).
- `APP_PORT` — порт для приложения (по умолчанию `8080`).
